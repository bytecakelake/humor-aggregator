# 로드맵

## 마일스톤

| 단계 | 내용 | 상태 |
|---|---|---|
| 설계 | 아키텍처, 규칙 표현 방식(CEL), 솔루션 구조 | 완료 |
| 콘텐츠 출처 선정 | 출처 후보 평가 및 수집 대상 확정 | 예정 |
| 데이터 모델·저장소 | 콘텐츠 스키마, DB, 마이그레이션 | 예정 |
| 수집 | 출처별 Collector 구현 | 예정 |
| 중복 제거 | 텍스트·이미지 유사도 판별 | 예정 |
| 규칙 엔진 | CEL 기반 사이트별 게시 규칙 | 예정 |
| 게시 | 사이트별 Publisher (첫 대상: 네이버 카페 Open API) | 예정 |
| 운영 | 파이프라인 연결, 스케줄러, 에러 처리·로깅·알림 | 예정 |
| 배포 | Terraform(OCI), Docker Compose, GitHub Actions | 예정 |

## 출처 선정 기준

- **콘텐츠 품질**: 저품질·자극적 콘텐츠 비율, 모더레이션 수준
- **갱신 빈도·양**: 새 콘텐츠 유입 속도, 출처 간 중첩도
- **수집 난이도**: 공식 API 유무, HTML 구조 안정성, 로그인·캡차 등 방어 수준
- **법적·정책 리스크**: robots.txt·이용약관상 허용 여부, 재게시 시 출처 표기 의무

## 알려진 제약

- 네이버 카페 Open API는 상품 게시판에 글을 쓸 수 없으며, 대상 카페에 대한 권한 범위와 호출 제한을 구현 전에 확인해야 합니다.
