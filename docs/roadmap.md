# 로드맵

## 마일스톤

| 단계 | 내용 | 상태 |
|---|---|---|
| 설계 | 아키텍처, 규칙 표현 방식(CEL), 솔루션 구조 | 완료 |
| 콘텐츠 출처 선정 | 출처 후보 평가 및 수집 대상 확정 | 예정 |
| 데이터 모델·저장소 | 콘텐츠 스키마, DB, 마이그레이션 | 예정 |
| 수집 | 출처별 Collector 구현 | 예정 |
| 중복 제거 | 게시 대상별 중복 판정(YouTube 영상 ID, 이미지·텍스트 유사도), 기존 게시물 목록 가져오기 | 예정 |
| 규칙 엔진 | CEL 기반 사이트별 게시 규칙, 일일 게시 한도 관리 | 예정 |
| 게시 | 사이트별 Publisher (첫 대상: 네이버 카페 Open API) | 예정 |
| 운영 | 파이프라인 연결, 스케줄러, 에러 처리·로깅·알림 | 예정 |
| 배포 | Terraform(OCI), Docker Compose, GitHub Actions | 예정 |

## 출처 선정 기준

- **콘텐츠 품질**: 저품질·자극적 콘텐츠 비율, 모더레이션 수준
- **갱신 빈도·양**: 새 콘텐츠 유입 속도, 출처 간 중첩도
- **수집 난이도**: 공식 API 유무, HTML 구조 안정성, 로그인·캡차 등 방어 수준
- **법적·정책 리스크**: robots.txt·이용약관상 허용 여부, 재게시 시 출처 표기 의무

## 알려진 제약

- 네이버 카페 Open API는 상품 게시판에 글을 쓸 수 없습니다.
- 글쓰기는 네이버 계정당 하루 200건으로 제한되며, 여러 카페에 게시하면 합산됩니다(카페 10곳이면 카페당 평균 20건).
- 카페는 도배 방지를 위해 하루 게시 건수가 많으면 글쓰기를 자동으로 제한할 수 있고, 기준은 공개되지 않습니다. 게시량은 측정하면서 조정합니다.
- 접근 제한 게시판, 특정 등급 이상만 쓸 수 있는 게시판, 카페 운영진이 설정한 금칙어·스팸 자동 차단(스팸 보관함으로 이동)은 카페 쪽 정책이므로 게시 방식과 무관하게 적용됩니다.
- 글쓰기 API는 이미지 첨부(multipart)를 지원하며, 본문은 HTML을 쓸 수 있습니다.
- 네이버 카페에는 게시판 글을 조회하는 공식 API가 없고, 자동 수집은 이용약관과 카페 공지상 허용되지 않습니다. 따라서 카페에 이미 올라온 글(다른 회원의 글, 멤버 공개 글 포함)은 자동으로 확인할 수 없습니다.
- 카페 글쓰기 한도를 늘리려고 여러 계정이나 여러 클라이언트 아이디를 쓰는 것은 약관상 허용되지 않습니다.
