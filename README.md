# humor-aggregator

여러 출처에서 유머 콘텐츠를 수집하고, 중복을 제거한 뒤 사이트별 규칙에 맞춰 자동으로 게시하는 .NET 프로그램입니다. 첫 번째 게시 대상은 네이버 카페이며, 사이트마다 다른 게시 규칙은 [CEL](https://github.com/google/cel-spec) 표현식으로 정의합니다.

## 기술 스택

- .NET 10
- Oracle Cloud Infrastructure (OCI)
- Terraform
- Docker Compose
