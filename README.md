# humor-aggregator

여러 출처에서 유머 콘텐츠를 수집하여 중복 없이 다양한 플랫폼(현재는 네이버 카페)에 자동으로 게시하는 프로그램입니다. 카페별로 상이하고 복잡한 게시 규칙을 스크립팅으로 정의할 수 있도록 설계합니다.

## 기술 스택

- .NET (LTS)
- Oracle Cloud Infrastructure (OCI)
- Terraform (IaC)
- Docker Compose (셀프호스팅)
